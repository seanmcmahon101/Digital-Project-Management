# Changelog

Notable changes to Digital Project Management are recorded here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and future releases use [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.1.0] - 2026-08-27

### Added

- Cross-platform continuous integration and tagged release automation
- Packaged Windows, macOS, and Linux release archives with SHA-256 checksums
- Getting-started, user, data-recovery, development, and troubleshooting guides
- Contribution, security, and GitHub community templates
- Complete, self-validating workspace backups containing the database and uploaded documents
- Portfolio-wide search with keyboard shortcuts
- First-class project hold and resume workflow with activity history
- Responsive navigation for phones and compact screens
- Loopback host and cross-origin request protections

### Changed

- Reworked repository presentation and download instructions for non-developers
- Moved new workspaces to stable per-user data locations while preserving legacy portable data
- Made stage transitions and preference updates transactional
- Strengthened accessibility, destructive-action safeguards, numeric validation, and CSV export safety
- Enforced project ownership for milestone, requirement, and RACI relationships

## [1.0.0] - 2026-08-24

### Added

- Local project-management workspace backed by SQLite
- Idea pipeline and project portfolio dashboard
- Project plans, tasks, milestones, RAID, decisions, stakeholders, and RACI
- Requirements, testing, scope baselines, and change control
- Business cases, financials, benefits, readiness, closure, and lessons learned
- PDF reporting and CSV/Excel project-register transfer
- Local document management and database backups
